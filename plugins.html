02

权限体系

文案已备，运行时未实现

Pages.Plugins.json 里预置了 8 种权限的文案与 ApiVersion 声明 （Perm.ServerStatus / Notify / Widget / NetworkReadonly / Storage / Network / Unknown / Readonly）， 还定义了启用/禁用按钮与不兼容提示。但 PluginsView.axaml.cs 只读 3 个字段，没有任何启停逻辑。
权限键语义
Perm.ServerStatus读取服务器状态
Perm.Notify发送通知
Perm.Widget注册桌面小组件
Perm.NetworkReadonly只读网络访问
Perm.Storage存储读写
Perm.Network完整网络访问
Perm.Readonly只读权限
Perm.Unknown未知权限（兜底）
03

插件包格式

.nekoex

插件包（zip）格式。启动器把它当目录项直接列出（PluginsView.axaml.cs:65-71）， 当前不解析内部内容。

plugin.yaml

清单格式，同时兼容 plugin.yml。创作中心的「插件清单生成」工具定位就是生成这份清单与权限声明。

NekoSolo 载荷结构

安装器读取的是 zip 载荷，files/ 与 overrides/ 必读并计入 payload 大小；minecraft/ 与 jre/ 识别但分开计数。

04

NekoSolo 安装器

安装流程
  • 读取载荷，统计 files/ / overrides/ 大小
  • 分别统计 minecraft/ / jre/ 条目数
  • CRC 校验
  • 写 solo.json + 安装标记
  • 创建桌面快捷方式 .lnk
安装目录
  • %UserProfile%\NekoSolo\{DisplayName}
  • 文件名非法字符自动替换为 _
  • 4 个面板：welcome / progress / done / about
打包缺口：安装器能读 files/ / overrides/、校验 CRC、写 solo.json； 但启动器导出的仍是 .zip 载荷，未追加 exe 尾标，需自行与安装器 stub 合并才能得到单文件。
