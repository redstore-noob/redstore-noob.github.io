01

双源曲库

本地音乐
  • 扫描本地文件夹
  • 支持 mp3 / flac / ogg / wav / m4a / aac / opus / wma 八种格式
  • NAudio + Media Foundation 解码
  • 未读 ID3 标签 标题直接用文件名
网易云音乐
  • 内置 WebView2 登录页：手机号 / 邮箱 / 扫码
  • 登录后直接读取 HttpOnly Cookie
  • 也支持手动粘贴 Cookie
  • 云端搜索 / 歌曲地址 / LRC 歌词
