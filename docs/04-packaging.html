打包与发布

把清单、详情、程序集、图标四件套压成一个 .nekoex，玩家双击即装。

关于打包#

插件的文件格式为.nekoex，格式本质为.zip格式，具体目录为:

  • info.yaml 存储关于插件展示信息的内容
  • description.md 在启动器详细信息中展示的Markdown描述文件
  • extension.dll 插件编译后产物
  • icon.png 插件在启动器内展示图标

包内四件套#

文件必填作用
info.yaml是插件清单，内容与开发期的 plugin.yaml 一致
description.md否插件详情页展示的 Markdown 简介
extension.dll是编译产物，发布前记得改名（开发期 DLL 名不限）
icon.png否插件在启动器内展示的图标
.nekoex 本质就是 zip：四个文件放在压缩包根目录，别再套一层文件夹。

发布流程#

  1. dotnet build -c Release 出 DLL，重命名为 extension.dll
  2. 按上表把四件套放进同一个目录（官方示例项目里附了 pack.ps1 一键打包）
  3. 压成 zip 后把扩展名改成 .nekoex
  4. 建 GitHub 仓库，仓库名与清单 id 保持一致；发 Release，tag 写版本号，资产上传 .nekoex
  5. 玩家在 下载 → 插件 粘贴仓库地址，即可在线安装与更新（见第五章）
