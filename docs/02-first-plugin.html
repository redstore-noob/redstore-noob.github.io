你的第一个插件

从零写一个圆形时钟：入口、控件、清单、打包、安装，五步走完，照抄能跑。

本章从零写一个真实可跑的插件：圆形时钟——它会弹一条提示，然后往桌面组件盒里加一个每秒走针的时钟。全程照抄能跑，改几行就是你自己的插件。

完整成品就在仓库 Mofumofu.Extension.Example/ 里，卡住时可以直接对照。

1. 创建项目#

按第一章第 3 节改好 csproj（引用 ExtensionAPI + 瘦身 Avalonia），然后加一个 ClockPlugin.cs：

2. 实现插件入口#

插件入口 = 实现 IMofuPlugin，宿主靠它认出你：

三个要点：

  1. Init(IPluginContext context) 是唯一的入口。context 上挂着全部能力域 （Popup / Widget / Pages / PageRegister / Wallpaper / Style / Game / Downloads / Config）， 想用什么顺着属性摸下去就行，完整清单见第三章。
  2. 返回 false 表示拒绝加载，抛异常则会在插件页显示"异常"状态和原因——两种都行，但别静默吞错。
  3. 每个能力调用都可能要求权限（见第 4 节清单里的 permissions），没声明会抛 PluginPermissionException。

5. 跑起来#

启动器 → 插件页 → 右上角重载按钮。你应该看到：

  1. 左下角弹出 Toast"圆形时钟插件已加载喵！"（notify 权限）
  2. 插件列表出现"圆形时钟"，状态徽章"已启用"
  3. 桌面右上角"+"打开组件盒，多了一个"圆形时钟"组件，拖到桌面上开始走针

6. 试试权限和热装卸#

  • 插件页 → 选中插件 → 权限标签 → 把"通知"关掉 → 重载插件：Toast 不再出现， 代码里的 context.Popup.Toast 会抛 PluginPermissionException
  • 概览页停用插件：组件从组件盒消失（宿主自动撤销了它的注册）；再启用又回来——这就是热装卸
  • 卸载会连 plugins/myclock/ 目录一起删掉，测试前注意备份

7. 打包发布#

发布 = 把四件套压成 .nekoex（本质是 zip，详见第四章）：

示例项目里附了 pack.ps1 一键打包。发布到商店的话：建一个 GitHub 仓库（仓库名 = 清单 id）， Release 传 xxx.nekoex 资产、tag 写版本号，玩家在 下载 → 插件 添加你的仓库地址即可在线安装/更新（见第五章）。
