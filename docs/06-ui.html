UI 扩展

任务栏托盘、桌面组件、页面注入、新页面、主题与样式——五个扩展点，全部走 context。

启动器界面的五个扩展点：任务栏托盘、桌面小组件、页面内容注入、导航页面、主题与样式。全部走 IPluginContext 的对应属性，UI 线程调度宿主已代劳。

1. 任务栏托盘：常驻小图标#

context.Taskbar（需要 widget 权限）往启动器任务栏右侧（版本选择框左边）加图标，点击行为完全由插件决定：

点击回调里弹窗和跳页面二选一或组合：

返回的 IDisposable 撤销句柄在插件停用/卸载时宿主会代为调用（图标自动消失），一般不用自己管。

2. 桌面小组件：进组件盒#

context.Widget（需要 widget 权限）把控件注册进桌面组件盒（主页右上角"+"打开），玩家拖出来摆：

组件 id 会自动加插件前缀（MyPlugin.clock），无需担心撞名。 把控件做"可卸载友好"的关键一条：定时器在 DetachedFromVisualTree 里停（见第二章 ClockWidget）。

3. 页面内容注入：三槽位#

context.Pages 往宿主已有页面的边缘插内容，不用注册新页面：

三个槽位：Banner（顶部，占高度）/ Footer（底部，占高度）/ Overlay（悬浮层，不占位）。 order 决定同槽位的先后；工厂每次进页面都会被调用，必须返回新控件（同一个控件实例不能挂两处）。 pageId 传 "*" 表示所有页面。

context.Theme 读宿主当前主题色，出 UI 的插件用它配色，玩家换主题自动跟手：

6. 样式与主题库#

context.Style 三种加载方式（都返回撤销句柄）：

axaml 根节点必须是 <Styles>。资源键请加插件 Id 前缀（如 MyClock.BackgroundBrush）避免多插件互抢。

主题库注意：随包依赖会被宿主装入默认 ALC 让 avares:// 可解析，代价是这些 DLL 被钉住—— 用主题库的插件可能要重启启动器才能完全卸载；主题库的 Avalonia 版本必须与宿主一致（当前 12.1.4）。
