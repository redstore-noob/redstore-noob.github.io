插件仓库镜像

借 GitHub / Gitee / GitCode 的 Release 做在线安装与自动更新，不用自己搭服务器。

启动器通过读取用户添加的仓库的最新 Release，实现插件在线安装与更新。

支持的托管平台#

平台仓库链接示例Release API
GitHubhttps://github.com/owner/repoapi.github.com/repos/{owner}/{repo}/releases/latest
Giteehttps://gitee.com/owner/repogitee.com/api/v5/repos/{owner}/{repo}/releases/latest
GitCodehttps://gitcode.com/owner/repoapi.gitcode.com/api/v5/repos/{owner}/{repo}/releases/latest

在「下载 → 插件」里粘贴任一平台的仓库链接即可添加，支持同时添加多个仓库；同一仓库在不同平台可以各添加一份（按平台 + owner/repo 去重）。

约定#

  • 仓库需要发布 Release，并在 Release 里附带 .nekoex 资产（见「4.打包」）。
  • 插件 id 约定 = 仓库名（owner/repo 的 repo 段），启动器用它关联已安装插件与商店条目。
  • 资产下载地址优先取 Release API 返回的 browser_download_url；缺失时按各平台约定拼直链兜底。
