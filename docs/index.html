🚀 入门

从源码构建并运行 NyaLauncher。请确保已安装 .NET 10 SDK，并在 Windows / macOS / Linux 上操作。

克隆与构建

git clone https://github.com/redstore-noob/NyaLauncher
cd NyaLauncher
dotnet build NyaLauncher.slnx
dotnet run --project NyaLauncher.Avalonia

环境准备、依赖说明与常见故障排查将在后续补充。

🧭 架构总览

NyaLauncher 采用分层架构：GUI 与核心逻辑解耦，通过插件契约向社区开放扩展能力。

分层设计

整体以解决方案 NyaLauncher.slnx 组织，包含前端、核心、插件、令牌保护与测试等多个模块。前端（Avalonia）只负责界面与交互，核心（Core）承载游戏管理、账号与版本解析等逻辑，二者通过清晰边界通信；插件契约（Plugin.Abstractions）则把扩展能力以稳定接口暴露给第三方。

完整的模块职责见 模块说明；想自己写插件请看 插件开发。

📦 模块说明

解决方案由以下六个模块组成。

🖥️
NyaLauncher.Avalonia前端 GUI，由 Avalonia 编写。
✨
NyaLauncher.Avalonia.Animations前端动画实现。
⚙️
NyaLauncher.Core核心功能实现。
🧩
NyaLauncher.Plugin.Abstractions插件契约，开放扩展接口。
🔐
NyaLauncher.MinecraftTokenCrypto对 Minecraft 令牌的保护。
🧪
NyaLauncher.Tests专门用于测试部分功能。

🧩 插件开发 API v1

通过 NyaLauncher.Plugin.Abstractions（SDK 0.1.0-ppre2，契约 1.0）扩展启动器：注册工作区组件、Minecraft 实例扩展与启动贡献。插件与宿主同进程运行。

⚠️ 安全：插件 DLL 与启动器同进程，能力授权不是沙箱，插件仍能调用 .NET 的文件 / 网络 / 进程 API。仅安装可信来源，并独立审查源码与依赖。

核心能力

在 plugin.json 声明所需能力，缺一项授权即无法启动。能力代表用户授权意图，并非宿主已实现的服务（当前 GetService<T>() 恒返回 null）。

ui.components ui.native network.http system.info.read user-files.read user-files.write process.start minecraft.instance.read minecraft.instance.modify minecraft.launch.modify

快速开始

从与目标 NyaLauncher 同版本的发布包取 NyaLauncher.Plugin.Abstractions.dll（通常随启动器可执行文件同目录），仅引用此 SDK DLL，不要引用 Avalonia / Core。

Example.Hello/
├─ sdk/NyaLauncher.Plugin.Abstractions.dll
├─ PluginEntry.cs
├─ plugin.json
└─ Example.Hello.csproj
{
  "manifestVersion": 1,
  "id": "dev.example.hello",
  "name": "Hello NyaLauncher",
  "version": "1.0.0",
  "apiVersion": "1.0",
  "entryAssembly": "Example.Hello.dll",
  "entryType": "Example.Hello.PluginEntry",
  "requiredCapabilities": ["ui.components"]
}
public sealed class PluginEntry : PluginBase
{
    protected override ValueTask OnStartAsync(CancellationToken ct)
    {
        var def = new PolygonComponentBuilder(
                $"{Context.Manifest.Id}/hello", "Hello World")
            .AddText("msg", new ComponentRect(0.08, 0.3, 0.84, 0.4),
                "Hello, NyaLauncher!", ComponentTextRole.Title, 22)
            .Build();
        Context.Registrar.AddComponentArea(new PluginComponentArea
        {
            Id = $"{Context.Manifest.Id}/area",
            Title = "Hello 插件",
            Components = [ new PolygonComponentRegistration { Definition = def } ]
        });
        return ValueTask.CompletedTask;
    }
}

构建 dotnet build -c Debug 后，把 plugin.json 与 DLL 放入插件包目录（Windows 默认 %LOCALAPPDATA%\NyaLauncher\plugins\packages\<id>），在启动器「插件列表」点击「重新扫描」即可。修改代码需先禁用 → 替换 DLL → 重新扫描 → 启用。

核心 API

PluginManifest插件元数据（id / name / version / entryType / capabilities…），来自 plugin.json。
IPluginContext提供 Manifest、Storage、Settings、Registrar 与 IsCapabilityGranted。
PolygonComponentBuilder流式构建工作区组件（文本/按钮/进度/滑块…），Build() 自动校验。
Minecraft 集成IMinecraftInstanceExtension 与 IMinecraftLaunchContributor 修改实例与启动参数。
