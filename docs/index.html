插件开发指南

这是启动器插件系统的完整开发文档：环境搭建、第一个插件、API 速查、UI 扩展与启动钩子，八章按顺序读一遍就能上手。

插件API由我设计，但文档可能有部分AI参与，如果您觉得有不妥之处，请提交ISSUE，我将尽我能力进行完善。

插件系统一览：插件是 .NET 类库（实现 IMofuPlugin），打包成 .nekoex 安装，与启动器同进程运行。 能做什么：桌面小组件、页面注入、任务栏/托盘常驻、主题与样式、实例与资源下载、启动钩子……全部能力见 第三章 API 对照表。

按插件类型定制路线#

插件清单里的 ExtensionType（PluginTypeEnum）决定你的插件在启动器里亮什么标签。 六种类型各有最合适的能力组合与章节路线，对号入座喵：

类型标签典型作品必用能力域推荐路线
Tool 工具圆形时钟、下载管理器Widget Taskbar SystemTray1 → 2 → 3 章 UI 域 + 6.UI 扩展 → 4
Theme 主题美化Material 换肤、暗色增强Style Theme Wallpaper1 → 2 → 3 章 + 6.UI 扩展 第 5、6 节 → 4
General 通用扩展模组市场、实例管理器ResourceDownload InstanceAction Downloads1 → 2 → 3 章 + 7.下载与实例 → 4
Optimize 优化JVM 参数调优、启动加速ILaunchAction.LaunchingAsync（注入参数）1 → 2 → 3 章 + 8.钩子 → 4
Patch 补丁前置模组检查、启动拦截ILaunchAction（Cancel）+ InstanceAction1 → 2 → 3 章 + 7.下载与实例 + 8.钩子 → 4
Function 功能扩展游戏时长统计、服务器监控Game 事件 + IDownloadAction 钩子 + Taskbar1 → 2 → 3 章 + 6.UI 扩展 + 8.钩子 → 4
所有类型通用的三章：第一章（环境）→ 第三章（当字典）→ 第四章（发布）； 想上架在线商店的再加 第五章。

文档规则#

  • 第三章是唯一的 API 速查表，只放签名 / 权限 / 行为表格；场景类教程放"按目标找章节"指向的位置
  • 第三章体量超过 300 行时按域拆分（3-UI / 3-下载 / 3-钩子），拆分前本目录会先更新
  • 数据 record 与枚举统一放在契约库 Data/ 目录，文档统一在第三章第 8 节索引
  • 新增 API 的规矩：先改第三章，再合并代码——文档欠账会直接挡住作者的落地

写插件前必读三条#

  1. 插件与启动器同进程运行：只安装可信来源的插件，权限开关是知情同意机制不是沙箱
  2. 清单里声明权限（permissions:），没声明的 API 调用会抛 PluginPermissionException
  3. 别在控件里起停不下来的后台线程 / 定时器——热卸载需要配合（详见第一章第 5 节）
