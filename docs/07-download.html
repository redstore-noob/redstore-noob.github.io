下载与实例

搜资源、装实例、管 mods、下 Java：四个接口覆盖完整下载链路。

四个接口覆盖"查版本 → 装实例 → 下资源 → 管模组 → 下 Java"的完整链路。 网络类失败全部直接抛异常（消息可直接展示给玩家），进度走 IProgress<T>，取消走 CancellationToken。

1. 资源搜索与安装（Modrinth）#

context.ResourceDownload——搜模组/光影/资源包并装进实例（走宿主镜像体系，境内可用）：

ResourceKind 三选一：Mod / Shader / ResourcePack。CurseForge 源暂未开放，当前全部走 Modrinth。

2. 安装游戏实例（原版或带加载器）#

context.Downloads：

返回的 InstanceInfo.Id 可能和版本号不同（如 1.21.4-fabric），后续操作一律用这个 Id。 插件只能安装实例，不能启动任意实例——启动走 context.Game.LaunchSelectedAsync()（只能启玩家选中的那个）。

3. 实例模组管理#

context.InstanceAction——列 / 启停 / 删实例 mods 目录里的模组：

权限提醒：列表要 readonly，启停和删除要 instanceWrite（删除不可恢复，玩家会盯着这个开关）。

4. Java 运行时#

context.Java——清单 / 安装 / 本机检测：

权限速查#

查询类（版本清单 / 搜索 / 文件列表 / Java 清单 / 本机检测）networkReadonly / readonly
安装类（实例 / 资源 / Java）network
mods 启停 / 删除instanceWrite
