FIELD NOTES / 12Settings

设置

5 大分区，从游戏路径到界面外观。所有外观开关都真的生效 —— 毛玻璃、不透明度、直角模式、跟随背景取色，一项不落。

5 分区三语言S 模式外观全生效
01

五大分区

顶部带搜索框，找设置项不用翻

游戏分区 1

游戏目录（改 / 重置）、Java（自动探测 / 设为默认）、内存上限。

通用分区 2

关闭行为（退出 / 最小化到托盘 / 每次询问）、单实例、S 模式、界面语言。

外观分区 3

主题、图标配色、强调色 + 自定义取色器、跟随背景、毛玻璃、卓越视效、不透明度、直角模式、开始栏位置。

网络分区 4

下载源、回落源、自定义源、测速、并行下载数、CurseForge Key、自动装前置。

关于分区 5

应用名、真实版本号、检查更新、项目主页、许可证。

02

外观与个性化

每一个开关都真的生效

逐项对照
  • 面板毛玻璃 —— 窗口不在前台时自动暂停模糊，不偷吃 CPU
  • 窗口不透明度 / 背景不透明度 —— 两条独立滑块
  • 直角模式 —— 当前页面面板与输入框圆角归零
  • 卓越视效 —— 恢复高光、阴影、折射、渐进模糊等额外渲染
  • 开始栏位置 —— 上 / 下 / 左 / 右 + 自动隐藏
  • 图标配色 —— theme / colorful 两档
强调色与跟随背景
  • 6 套预设强调色 + 自定义取色器（自研 HSV 拾色轮）
  • 最近使用列表，上限 8 个
  • 跟随背景 —— 从壁纸预览算平均色，挑最接近的主题色
  • 换色即时生效，自绘控件也一起跟着变
03

S 模式与本地化

轻量模式 + 三语言即时切换

S 模式（简洁模式）
  • 隐藏开始栏与开始菜单
  • 首页变成一屏「选版本 → 选账号 → 开玩」
  • 保留 5 个页面：home / download / instances / account / settings
  • 可随时退出
  • 无 OOBE —— 不再有首次启动引导流程，启动直接进桌面
本地化
  • 内置 简体中文 / English / 跟随系统 三种语言
  • 切换即时生效，不用重启界面
  • 覆盖全部界面文案：设置、下载、实例、服务器、账户、创作工具、组件说明
  • 不翻译游戏内容：实例名 / 服务器名 / MOTD / 曲名
