02

外观设置的真实性

每一项都真的生效

逐项对照
  • 面板毛玻璃 —— Fluid.Avalonia.Acrylic，窗口不在前台时自动暂停模糊降 CPU
  • 窗口不透明度 / 背景不透明度 —— 两条独立滑块
  • 直角模式 —— 当前页面面板与输入框圆角归零
  • 卓越视效 —— 恢复高光、阴影、折射、渐进模糊等额外渲染
  • 开始栏位置 —— 上 / 下 / 左 / 右 + 自动隐藏
  • 图标配色 —— theme / colorful 两档
强调色与跟随背景
  • 6 套预设强调色 + 自定义取色器（自研 HSV 拾色轮）
  • 最近使用列表，上限 8 个
  • 跟随背景 —— 从壁纸预览算平均色，挑最接近的主题色
  • 换色即时生效，含 code-behind 自绘元素

04

S 模式与本地化

S 模式（简洁模式）
  • 隐藏开始栏与开始菜单
  • 首页变成一屏「选版本 → 选账号 → 开玩」
  • 保留 5 个页面：home / download / instances / account / settings
  • 可随时退出
  • 无 OOBE —— 不再有首次启动引导流程，启动直接进桌面
本地化
  • 内置 简体中文 / English / 跟随系统 三种语言
  • 存储于 Localization/<lang>/<Area>.json
  • zh-CN 与 en-US 各 1853 键，完全对齐
  • 切换即时生效：XAML 走 {{DynamicResource L.xxx}}，code-behind 随页面重建刷新
  • 不翻译：实例名 / 服务器名 / MOTD / 曲名 / MofuCore 后端消息与日志
