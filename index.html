项目一览

五个模块，职责边界清晰；UI 与 Minecraft 逻辑彻底解耦

MofuCore25,873 行

Minecraft 逻辑核心库，25,873 行 / 31 文件。不含任何 UI 引用，纯粹的业务内核。

Mofumofu.Backend467 行

启动器自身的后端：本地设置持久化、日志写入、外部链接唤起。仅 467 行，极薄。

Mofumofu.Launcher35,912 行

Avalonia 前端主体，35,912 行 / 77 文件。所有视图、控件、服务、主题系统。

Mofumofu.Classic7,073 行

同内核的另一套宿主（Photino.NET），7,073 行 / 24 文件，16 个反射注册的 API 模块。

NekoSolo1,965 行

独立的单文件整合包安装器（WPF），1,965 行。负责 CRC 校验、解压、建快捷方式。

02

核心能力

每一项都接真实后端，不是演示占位

下载与安装
  • Minecraft 本体正式版下载，带磁盘缓存与 CheckBox 组筛选器
  • 5 大加载器：Fabric / Quilt / Forge / NeoForge / OptiFine，各自独立实现类
  • Modrinth 搜索与安装：mod / 整合包 / 光影 / 材质包四类资源
  • Java 环境探测与 Mojang 官方运行时下载
  • 多镜像源：官方 / 镜像 / 自定义，含回落源与测速选最快
账户与启动
  • 三种登录：Microsoft 正版（PKCE + 设备码）、Authlib 皮肤站、离线账号
  • 凭据加密：DPAPI / Keychain / libsecret 三系统原生实现
  • 启动参数装配：仅在用户未手写时才注入 -Xms / -Xmx
  • G1GC 调优：按机器分档，低配关高配开
  • 类终端控制台：阶段时间线 + 等宽输出 + 命令行输入
服务器与联机
  • 4 种服务端核心：paper / vanilla / fabric / neoforge
  • 完整 RCON：Source RCON 协议实现，含鉴权与指令通道
  • 热备份：save-off / save-all 刷盘，运行中也能备份
  • 玩家管理：白名单 / OP / 封禁名单结构化读写
  • 陶瓦联机：Terracotta 客户端适配，5 态状态机
创作与桌面
  • 8 个创作工具：资源包 / 命令 / 渐变文字 / 立方体 3D / 皮肤 / 整合包 / NekoSolo / 插件
  • 3D 皮肤编辑器：64×64 展开图涂色，模型实时更新
  • 22 个桌面小组件：格子板自由摆放，真实数据源
  • Rewind 时光回溯：内容寻址快照，回滚前自动备份
  • 壁纸系统：libVLC 视频壁纸 + 本地图片轮播

04

设计系统

没有一处硬编码颜色 —— 全部走令牌

整个界面共用 41 个颜色令牌，命名规则为 Neko{语义}{状态}Brush。 深浅两套色值与 6 套强调色由 ThemeManager 统一计算，切换即时生效（含 code-behind 自绘元素）。

05

已知缺口

如实记录，不粉饰

README 中的 Wallpaper Engine 章节已完全过时。 代码里 webwallgl / scene.pkg 零命中，实际改用 libVLC 渲染视频壁纸（WallpaperVideoHost.cs:13 明确注释「不使用 WebView2」）。
功能缺口
  • CurseForge 完全未适配，Download/Curseforge/ 只有一个 info.md，API Key 仅保存不消费
  • 插件运行时未实现 —— 只扫描目录，不加载插件代码；权限体系只有文案没有逻辑
  • 8 个桌面组件被硬过滤掉（playtime / quickjoin / rss / music / download / network / goal / screenshots）
  • 联机只接了 1 个服务商，索引 1 及以上直接返回 null
  • Rewind 仅覆盖本地，无云同步
细节问题
  • 网易云部分歌曲需 VIP，接口只返回试听片段或空地址
  • 本地音乐未读取 ID3 标签，标题直接用文件名
  • NekoSolo 导出的仍是 .zip 载荷，未追加 exe 尾标，需自行与 stub 合并
  • README 称本地化 1826 键，实测 zh-CN / en-US 各 1853 键
  • ParallelDownloads 注释写 1-16，实际默认值是 32
