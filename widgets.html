自由摆放的桌面

HomeView.axaml

交互
  • 8 列网格，长按磁贴 1 秒浮现格子线
  • 拖动吸附 + 落点预览
  • 拖到开始栏即移除：幽灵卡跟随指针，底部显示红色「松手移除」提示

03

统一原语

WidgetChrome.cs —— 429 行

所有组件共用 WidgetChrome 提供的 28 个构建原语： Card / Stat / Pill / Bar / ListItem / ChipButton / EmptyStateCard 等， 保证 22 个组件的视觉与交互完全一致。

定时器统一管理：所有组件遵循「定时刷新 + 不可见时停表」—— WidgetChrome.OnBecameVisible:429 与 OnDetach:428 负责挂起与恢复。 组件滚出视野就不再空转刷新，省 CPU 也省电。
