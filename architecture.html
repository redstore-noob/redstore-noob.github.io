技术架构

五个模块，职责边界清晰。UI 与 Minecraft 逻辑彻底解耦：同一份 MofuCore 内核，既能跑在 Avalonia 桌面上，也能跑在 Photino Web 宿主里。

Avalonia 12.NET 10跨平台内核零 UI 引用
01

分层结构

UI 与 Minecraft 逻辑彻底解耦，同一份内核可换宿主

表现层

桌面版跑在 Avalonia 12 上，经典版跑在 Photino.NET 上 —— 同一套内核，两种外壳。

视图、控件、主题、交互全在这一层，换宿主不影响内核。

后端层

只负责启动器自己的事：设置存储、日志、唤起浏览器。

刻意做得很薄 —— 游戏相关的配置一律交给内核。

内核层

MofuCore：版本、加载器、账户、启动、服务器、联机， 全部 Minecraft 逻辑都在这里。

零 UI 引用，可被任意宿主复用。

02

内核能力域

启动器要处理的每一件事，内核里都有归口

域管什么
配置游戏目录、Java、内存的分域配置，默认落在 ./.minecraft
下载版本清单、资源与库依赖解析、断点与多线程下载
加载器Fabric / Quilt / Forge / NeoForge / OptiFine 各自独立实现
Modrinthmod / 整合包 / 光影 / 材质包四类资源的搜索、安装与打包
Java环境变量、注册表、常见目录三路探测；Mojang 运行时下载
启动启动参数装配、继承链合并、进程拉起与退出监听
账户Microsoft / Authlib / 离线三种账号，令牌加密存储
服务器进程管理、RCON 指令、热备份、玩家列表
工具内存与磁盘占用、资源包打包、时光回溯快照
联机陶瓦联机客户端适配
日志运行日志实时输出与崩溃原因推测
