03

SukiUI 实际用量

关键发现：SukiUI 只提供了外壳，交互控件全是原生 Avalonia 自绘

全项目 grep Suki[A-Za-z0-9_]+ 的结果：SukiWindow × 6、SukiDialogHost × 8、SukiDialogManager × 1、 SukiTheme × 3、SukiColorTheme × 3、GlassCard × 8、InfoBar × 1。 没有用到 SukiButton / SukiToggleSwitch / SukiComboBox / SukiNumericUpDown / SukiTabControl / SukiTextBox / SukiToast / SukiSideMenu。
用到的 SukiUI 能力
  • SukiWindow —— 无边框外壳，标题栏 / 阴影 / 圆角随主题
  • SukiDialogHost + Manager —— 模态对话框宿主
  • SukiTheme / SukiColorTheme —— 全局主题注册与强调色切换
  • GlassCard —— 毛玻璃卡片（创作中心 / 实例 / 联机）
  • InfoBar —— 下载大厅的中国大陆合规警告条
自己实现的部分
  • Toast —— 自绘 ToastStack，最多 4 条，异步淡出
  • 按钮 / 输入框 / 下拉 / 开关 —— 原生 Avalonia 控件 + Classes="primary" 等自定义样式类
  • ColorWheel —— 自研 HSV 拾色轮（色相环 + 饱和度盘 + 明度条）
  • IconParkIcon —— 自研多色矢量图标控件
  • GradientSpinner —— 自绘旋转渐变加载圈

<span class="c">// 所以主题名必须带递增序号，否则换强调色无效</span>
<span class="k">private</span> <span class="k">int</span> _sukiThemeSerial = <span class="n">0</span>;

<span class="k">var</span> theme = <span class="k">new</span> SukiColorTheme(...);

04

Classic 宿主

同内核的另一套前端：Photino.NET + 16 个反射注册 API

Mofumofu.Classic/Program.cs 的入口注释直书「Mofumofu 启动器（Photino.NET 宿主）」。 启动流程是：日志 → 本地设置 → StaticServer(wwwroot) → AppWindow + Bridge → 反射注册程序集里所有 ApiBase 子类 → runtime 命令 → Load。

05

构建与运行

前置要求
  • .NET 10 SDK
  • WebView2 Runtime（Win11 自带，Win10 需装 Evergreen）
  • 首次启动自动创建 ./.minecraft 版本文件夹
常用命令
<span class="c"># 运行桌面版</span>
dotnet run --project Mofumofu.Launcher

<span class="c"># 经典版（Web 前端）</span>
dotnet run --project Mofumofu.Classic -- --dev
<span class="c">#   默认连 http://127.0.0.1:5173 的 Vite dev server</span>
